# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-15

### Added

- JSON Studio: validation with line/column errors, collapsible tree with click-to-copy JSONPath, JSONPath queries, JSON → TypeScript generation.
- Regex Lab: live highlighting, capture groups, replace preview, token explanations, presets, Web Worker execution with a timeout.
- JWT Inspector: decoding, claims with expiry countdown, HS256/384/512 verification and re-signing.
- Diff Studio: Myers line diff with word-level highlights, split and unified views, patch export.
- Codec Pipeline: chainable, drag-to-reorder transforms for encodings, hashes, text case and timestamps.
- Socket Console: WebSocket client with filtering, byte counters and log export.
- Smart paste, command palette, keyboard shortcuts, compressed share links, light/dark/system themes, offline PWA.
